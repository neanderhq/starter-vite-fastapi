# Authlib Google OAuth + server sessions, version 1

Requires the Postgres block. Add `uv add authlib==1.8.0 httpx2==2.12.0 itsdangerous==2.2.0`. Copy this block's `.example` files to their shown project-relative paths without the suffix. In `app.py`, after creating `app` and **before all protected routes and the API catchall**, import `install_auth` and set `current_user = install_auth(app)`. The Postgres block loads `.env.local` first. Add `auth_models` to the models import in `migrations/env.py`, inspect the included additive migration, and run `uv run alembic upgrade head` explicitly.

Local `.env.local` needs a new 32-byte random `SESSION_SECRET`, `GOOGLE_CLIENT_ID`, and `GOOGLE_CLIENT_SECRET`. `AUTH_BASE_URL` defaults to Vite's `http://localhost:5173`; production requires the bound HTTPS origin. Add required `web` recipe requirements: `AUTH_BASE_URL` uses `source: provisioned, provider: Neander, binding: public_origin`; `SESSION_SECRET` uses `source: generated, generator: opaque-random`; both Google variables use `source: user`. Keep Neon `DATABASE_URL` and `migration: fastapi-alembic`. No secret enters Docker build or committed files.

Register `<planned origin>/api/auth/callback/google` with Google. Navigate the browser to `/api/auth/login/google`; the callback stores an opaque app-session token in an HttpOnly cookie and only its hash in Postgres. Authlib verifies OAuth state/OIDC identity; PKCE is enabled. The temporary signed state cookie contains no provider access/refresh token. The immutable Google subject owns the account; no automatic email linking occurs.

Use `Depends(current_user)` for private API handlers and scope all record queries by the returned user `id`. Installing this block does not silently protect the public todo example. The dependency rejects unsafe methods unless their Origin equals the configured frontend origin. `/api/me` is protected; POST `/api/auth/logout` revokes the session. Keep production origin HTTPS; localhost HTTP is for development only.

Verify anonymous/expired sessions return 401, foreign-origin writes return 403, a forged callback state returns 400, the session survives server restart, and logout invalidates the stored token. Actual Google login/callback requires provider credentials and registered URLs, so a local mocked-provider test does not certify live OAuth. Source: [Authlib Starlette integration](https://docs.authlib.org/en/latest/client/starlette.html), [Starlette SessionMiddleware](https://www.starlette.io/middleware/#sessionmiddleware).

With a disposable development database, `PYTHONPATH=. uv run python .neander/check-auth.py` checks anonymous/forged-state rejection, a seeded persisted session, CSRF and logout; it removes its test user. Authlib 1.8 uses the maintained [HTTPX2 client](https://httpx2.pydantic.dev/).
